# Arrum Kurniati — Professional Portfolio

Website portofolio statis HTML, CSS, dan JavaScript untuk deployment di Vercel.

## Cara melihat di komputer
1. Ekstrak ZIP.
2. Buka `index.html` di browser.

## Deploy ke Vercel
1. Buka https://vercel.com/new dan masuk akun.
2. Cara paling mudah dan stabil: unggah folder ini ke repository GitHub, lalu impor repository tersebut di Vercel.
3. Untuk proyek HTML/CSS/JS statis, pilih Framework Preset `Other`; Build Command dikosongkan; Output Directory `.` (root).
4. Klik Deploy. Setelah berhasil, Vercel akan memberikan URL publik.

Dokumentasi Vercel: https://vercel.com/docs/deployments/overview

## Struktur
- `index.html` — isi dan struktur halaman
- `styles.css` — desain responsif
- `script.js` — menu, tema gelap, animasi, salin email
- `assets/images/` — foto profil, pengalaman, dan galeri
- `assets/documents/` — CV dan sertifikat PDF

## Sebelum dipublikasikan
- Pastikan semua foto dan informasi sesuai.
- Website ini publik. Dokumen STR dan sertifikat yang ditautkan dapat diakses siapa saja yang memiliki tautan. Hapus atau ganti tautan dokumen yang tidak ingin dibagikan secara publik.
- Tautan LinkedIn dan publikasi sudah dimasukkan dari informasi yang tersedia.
- Periksa semua tampilan di desktop dan HP setelah deployment.

## Catatan
Skill bar adalah elemen visual dekoratif, bukan hasil penilaian kemampuan.
